# 🌿 Web Consultorio Médico Estético

Este proyecto es un sitio web estático desarrollado para un consultorio de medicina estética.  
El objetivo principal es ofrecer a los pacientes un espacio donde puedan conocer los servicios, la ubicación y la información de contacto del consultorio.

## 🚀 Características
- Página informativa con diseño sencillo y accesible.
- Secciones principales:
  - Inicio
  - Servicios
  - Sobre nosotros
  - Contacto
- Adaptado para distintos dispositivos (responsive design básico).

## 🛠️ Tecnologías utilizadas
- **HTML5**
- **CSS3**
- **JavaScript** 
- **Bootstrap**
